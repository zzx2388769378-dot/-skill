## 热门题材

### 热门-1 · 规则智斗 / 神明博弈

- **类型标签**：无限流、奇幻悬疑、智斗、群像
- **趋势依据**：2025 年「新网文」代表作以神明排位、规则博弈、反套路布局为核心（《诸神愚戏》《十日终焉》等），读者愿为逻辑反转与信息差博弈买单
- **目标读者/平台**：男频偏全年龄；起点、番茄
- **题材说明**：主角被卷入一套自洽的「游戏规则」——神明、命途、副本或排位体系。不靠无脑升级，靠谎言、布局、规则漏洞破局。读者要的是「每章都有钩子」的智斗爽感，以及群像角色的命运交织。
- **拟定书名**：**《诸局愚人簿》**
- **书名意境**：「诸局」暗示多重博弈与神明棋局；「愚人簿」点出主角以愚者姿态入局、实则记账布局——与规则智斗题材高度呼应

### 热门-2 · 现实行业文

- **类型标签**：现实主义、行业职场、近未来、社会议题
- **趋势依据**：2025 作协报告与起点数据均显示现实题材大幅增长，《飞流之上》等作品证明「专业行业 + 时代纹理」可出精品
- **目标读者/平台**：全年龄；起点、晋江（偏剧情向）
- **题材说明**：以某一具体行业（港口调度、基建、医疗冷链、能源电网等）为切口，写普通人在系统性压力下的选择与代价。读者要的是真实感、职业细节、以及「小人物撬动大系统」的情绪共鸣。
- **拟定书名**：**《潮汐调度员》**
- **书名意境**：「潮汐」既是港口自然规律，也是时代洪流的隐喻；「调度员」是平凡岗位，却掌握着生死攸关的排程权——现实行业文的典型张力

### 热门-3 · 无 CP 事业型女主 / 幻想未来

- **类型标签**：幻想未来、无 CP、大女主、废土/末世、剧情向
- **趋势依据**：晋江 2025—2026 榜单显示无 CP 区与「搞事业大女主」讨论度显著高于传统恋爱至上模式（如《我在废土世界扫垃圾》类作品）
- **目标读者/平台**：女频；晋江
- **题材说明**：女主在末世、废土或异变世界中以「编纂、修复、守望」类职业为核心驱动力，感情线非主线。读者要的是女性主体性、世界观沉浸感，以及「在废墟上重建秩序」的成就感。

- **书名意境**：「拾阶」是拾级而上的行动感；「守望」是职责与孤独；「录」暗示记录、编纂——契合女主在废墟中建档、守序的叙事核心

## 创新题材

### 创新-1 · 赛博修仙 / 金融反讽

- **类型标签**：东方玄幻、黑色幽默、社会讽刺、轻科幻
- **趋势依据**：2025 蓝皮书点名《没钱修什么仙？》等「赛博修仙」作品打破类型成规，将金融资本逻辑植入修炼体系，幽默荒诞中反讽阶层固化
- **目标读者/平台**：男频偏全年龄；起点、番茄
- **题材说明**：修仙世界被公司化、金融化——灵石有利率、渡劫要排期、功德算 KPI。主角以现代金融/打工人的视角解构修仙规则，在荒诞中照见现实。读者要的是脑洞 + 讽刺 + 反套路爽感。
- **创新点**：把「修炼」写成「资产负债表」，用年化、分期、杠杆等概念重构修仙经济
- **风险/难度**：需较强世界观与经济逻辑自洽，幽默与严肃的平衡要拿捏
- **拟定书名**：**《灵石年化率》**
- **书名意境**：「灵石」是修仙硬通货；「年化率」是现代金融术语——书名本身即题材宣言，一眼看出赛博修仙 + 金融反讽

### 创新-2 · 民俗志怪 / 治愈悬疑

- **类型标签**：民俗志怪、悬疑治愈、江南地域、单元剧
- **趋势依据**：知乎盐言 2025 年寻求推理、治愈、民俗志怪向叙事突破；东方克苏鲁、规则怪谈等小众类型各有拥趸
- **目标读者/平台**：全年龄；晋江、盐言、自出版
- **题材说明**：以江南老宅、灶神、河灯、纸鸢等民间信仰为壳，写「檐下异闻」——每件旧物、每个习俗背后都藏着一段未了的执念。单元剧结构，悬疑中带治愈，志怪中有人情。
- **创新点**：不走血腥恐怖路线，以「灶尾、檐下、河灯」等日常空间承载异闻，偏治愈悬疑而非纯惊悚
- **风险/难度**：民俗考据需扎实，单元剧需控制节奏避免松散
- **拟定书名**：**《灶尾遗誓》**
- **书名意境**：「灶尾」是厨房最不起眼的角落，民间信仰中灶神所居；「遗誓」是跨越生死的未竟之约——民俗志怪 + 人情温度的核心意象

### 创新-3 · 非人类视角 / 生态末世

- **类型标签**：末世进化、生态科幻、非人类视角、哲学向
- **趋势依据**：2025 蓝皮书点名《这个地下城长蘑菇了》以菌类视角反向重构地下城叙事；《菌毯之上》等作品以「菌丝纪年」构建新时间观
- **目标读者/平台**：男频偏全年龄；起点
- **题材说明**：主角非人——真菌、孢子、菌丝网络的意识碎片。在人类文明的废墟上，以「覆土、共生、纪年」的方式记录地球生态的重构。读者要的是视角新鲜感、硬核生态设定，以及对「何为文明」的哲学追问。
- **创新点**：叙事主体是菌丝/孢子，时间以「覆土纪」计量，人类成为背景而非中心
- **风险/难度**：非人类视角的情感共鸣难写，需找到读者可共情的锚点
- **拟定书名**：**《覆土纪事》**
- **书名意境**：「覆土」是菌类生长、掩埋废墟的动作，也是新生态覆盖旧文明的过程；「纪事」是编年体记录——非人类视角的末世史诗
