**作品简介**：

天空出现倒计时：距离现实维护还有 7 日。

班主任周予眼前浮现「末日存档系统」——完成他人未竟之事，才能降低遗憾值，换取有限的存档槽位。第七日零点，未被存档的人将从一切记录与记忆中抹除。

班级四十七人，只有三个槽位。第一个任务是帮林小满寄出迟了三年的信。第三个任务后，系统问他：你的遗憾值全组最高，是否用管理员权限存档自己？

周予选否。课代表许行舟却在悄悄把槽位让给别人。

被记住，和被爱，是不是同一回事？

```

```
被记住，和被爱，是不是同一回事？当存在变成可分配的名额，「负责」是拯救，还是另一种逃避？

## WORLD · 世界观

### 时代与地点

- 时代：现代（近未来无科技跳跃）
- 主要地点：云岭县第二中学（高三 17 班教室、邮局、操场、教务处）
- 社会背景：普通县城高中；全球同步出现天空倒计时与系统界面，无政府有效解释

### 核心规则

```rules
规则1：现实维护倒计时 7 日；第七日零点对本分支执行格式化——未存档者从一切记录、记忆、数字痕迹中抹除，不是物理爆炸。
规则2：备份区是平行现实分支；被存档者迁入，原分支不再留有存在证明。
规则3：遗憾值 = 个人未完成因果权重；须通过完成「他人」未竟之事任务降低；不能刷怪、不能购买、不能替自己完成任务。
规则4：存档槽位为存在名额；初始班级共享 3 槽；随日开放年级/全校池，总量有限不增；拒绝管理员自保后班级池缩减 50%。
规则5：第三个任务完成后触发管理员权限：存档自己则失去分配权；拒绝则宿主遗憾值权重上升，系统加大后续任务难度。
规则6：槽位可转让，不可逆；转让入口隐藏，系统不主动说明；转让后原持有者槽位显示「已占用：他人」。
规则7：备份预览（第 6 日）：已分配槽位者可短暂进入备份区预览，原现实出现重影，预览者记录开始淡化。
规则8：系统提示须公文式、冷句；界面仅相关可见者可见（初期仅 17 班师生可见班级界面，后扩全校）。
规则9：本卷结局开放式：不确证周予是否消失、不确证格式化是否完成、不展开备份区长期生活。
```

## STYLE · 文风参考

### 风格关键词

克制现实、短句、少形容词、系统提示像公文、情感藏在动作里；参考余华式冷静，不煽情。

### 文风样例

```
天空里的数字没有声音。

7 日。6 日。5 日。它只管往下走。

周予站在讲台上。下面四十七张脸，有的抬头看窗外，有的低头看桌面——桌面也有数字，和天上一样。

【系统提示】当前分支：云岭县第二中学。共享存档槽位：3。

他把粉笔折断又换了一支。折断的那截掉进槽里，没有响。

林小满坐在第三排。抽屉没关严，信封露出一角。系统说，那封信迟了三年。

周予合上教案。

「早读暂停。」他说，「林小满，跟我出去。」
```

### 对话风格

- 对话占比：约 35%
- 内心独白：少，用动作与系统提示代替
- 描写密度：环境简笔，重对话与系统冷句；不写长篇心理分析
