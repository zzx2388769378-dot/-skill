# 番茄小说 · 平台标签模板

> Agent 写 `listing.md` 时须引用本目录 JSON，并填写 **名称 + ID**（后台填表与 API 对齐）。

## 文件

| 文件 | 类型 | 说明 |
|------|------|------|
| `platform-reading-tags.json` | 阅读标签 | `label` = 主分类 / 主题 / 角色 / 情节 |
| `platform-content-tags.json` | 内容标签 | `group_name` = 情节 / 情感 / 人设 / 世界观 |

## 阅读标签（`platform-reading-tags.json`）

API 字段：`category_id`, `name`, `label`, `description?`

| label 值 | 用途 |
|----------|------|
| **主分类** | 作品主频道，通常选 1 个（如「科幻末世」） |
| **主题** | 题材底色，可多选（赛博朋克、规则怪谈…） |
| **角色** | 主角/配角类型（无女主、反派…） |
| **情节** | 阅读向情节标签（末世、求生、废土…） |

> 阅读标签与下方「内容标签」是**不同栏位**；勿混用 ID。

## 内容标签（`platform-content-tags.json`）

API 字段：`label_id`, `group_id`, `group_name`, `name`, `gender`

| group_name | group_id | 上限 |
|------------|----------|------|
| 情节 | 9182 | 4 |
| 情感 | 9183 | 2 |
| 人设 | 9184 | 4 |
| 世界观 | 9185 | 1 |

`gender`：0=通用，1=男频倾向，2=女频倾向（选标签时优先与目标读者一致）。

## listing.md 写法

```markdown
## 阅读标签

### 主分类（1）
- 科幻末世（category_id: 8）

### 主题
- 赛博朋克（873）
- 规则怪谈（851）

### 角色
- 无女主（391）

### 情节
- 末世（68）
- 求生（379）

## 内容标签

### 情节（≤4）
- 异族入侵（label_id: 9239）

### 情感（≤2）
- 无CP（9411）

### 人设（≤4）
- 非人类（9653）

### 世界观（≤1）
- 规则怪谈（9740）
```

## Agent 选取原则

1. **主分类**必须与正文类型一致（本书：科幻末世 `8`）。
2. **内容标签**遵守四分类上限；文风词（慢热、硬核）写入简介，不占用内容标签位。
3. 异种主角：人设优先 `非人类`（9653），勿再用 `精灵` 凑合。
4. `无女主`（9414）属**情感**组，不是人设组。
5. `规则怪谈` 在阅读标签为**主题**（851），在内容标签为**世界观**（9740）——同名不同 ID，填表时勿混。
6. 平台库更新时：替换本目录 JSON 并改 `exported` 日期。
